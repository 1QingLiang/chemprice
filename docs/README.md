# ChemPrice 开发文档

ChemPrice 化工价格平台（小程序版）的开发文档仓库。

## 内容

| 文档 | 说明 |
|---|---|
| 小程序需求文档 | PRD v1.1：MVP 范围、主体与合规前置约束、功能需求、权限与订阅模型、技术方案、里程碑、风险登记册 |

## 发布方式

由 publish_docs.py 自动同步（本地执行）：

    python publish_docs.py -m 描述本次改动

脚本会依次完成：HTML 结构校验 → 凭据泄露自查 → 上传服务器 → 提交并推送本仓库。

## 约定

- 每次新增/修改功能，**同步更新文档并发版**（不积压）
- ⛔ 文档内不得出现任何凭据（密码、密钥、Token）
- ⛔ 不得出现数据供应商名称，统一「数据来源：ChemPrice 化工价格平台」
