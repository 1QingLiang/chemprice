⛔ 通用约定

  1. 统一响应体：{ code, message, data }。业务错误同样以 HTTP 200 返回，必须判 code，不能只看 HTTP 状态码。
  2. 鉴权：JWT（HS256），请求头 Authorization: Bearer <token>。/api/admin/** 需 ROLE_ADMIN。
  3. 限流（nginx 层，按 IP）：cp_auth 10r/m、cp_api 600r/m、cp_open 120r/m、cp_static 900r/m，超限返回 429。
  4. 交易日：非交易日不更新行情数据，接口返回的 data_date 会停留在上一交易日，属正常。
  5. 分页接口必须传分页参数；/api/prices 超时设置不得低于 10 秒。

附录 · 上线前建议复核项

  1. /api/wechat/mp 三个接口是微信公众号服务器回调地址，不经过 JWT，需确认签名校验有效。
  2. /api/health 公开无鉴权，确认不泄露敏感信息。
  3. /api/admin/** 共 45 个接口，确认全部走 hasRole("ADMIN")。
  4. /api/ai/export 用签名 token 而非 JWT，确认 token 有效期与不可伪造。
  5. QQ 机器人相关接口（AdminQqController，8 个）已于 2026-09-24 整体下线，建议确认是否仍可访问。
